# Вместе — Telegram Mini App

Готовая сборка мини-приложения (GitHub Pages) и серверный модуль для Supabase Edge Function `vmeste`.

- Приложение: https://linass1097.github.io/vmeste-app/
- Бот: https://t.me/VmestePlanner_bot
- `server/vmeste-*.js` — серверная логика, её подгружает функция `vmeste` в Supabase. Секретов здесь нет: токен бота и ключи хранятся в базе Supabase.
